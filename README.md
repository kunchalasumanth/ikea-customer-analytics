# IKEA Customer Segmentation & RFM Analysis

## Project Overview

This project focuses on analyzing IKEA retail customer data to understand purchasing behavior, sales performance, and customer value using RFM (Recency, Frequency, Monetary) analysis.

The project combines SQL, Python, and Power BI to clean, analyze, and visualize customer data and generate meaningful business insights.

## Objectives

- Analyze sales and customer purchasing patterns.
- Identify high-value customers.
- Segment customers using RFM analysis.
- Understand customer spending behavior.
- Support data-driven business decisions.

## Tools & Technologies

- **SQL Server:** Data cleaning and querying.
- **Python:** Data analysis using Pandas.
- **Power BI:** Interactive dashboard and visualization.
- **Jupyter Notebook:** Python analysis.

## Project Workflow

1. **Data Cleaning:** Checked and prepared the retail dataset using SQL.
2. **Data Analysis:** Analyzed customer and sales information.
3. **RFM Analysis:** Calculated Recency, Frequency, and Monetary scores using Python.
4. **Customer Segmentation:** Grouped customers based on RFM scores.
5. **Dashboard Development:** Created an interactive Power BI dashboard.

## RFM Analysis

- **Recency:** How recently a customer made a purchase.
- **Frequency:** How frequently a customer purchased.
- **Monetary:** How much money a customer spent.
